# Street-Cats

## Backend

```bash
cd backend
npm install
npm run dev
```

> Il server parte su `http://localhost:3005`

### Variabili d'ambiente (`.env`)
```
PORT=3005
JWT_SECRET=mettiquiunachiavelungaesicura123456789
DATABASE_URL=postgresql://postgres:password123@localhost:5432/streetcats
```

---

## Frontend

```bash
cd frontend
npm install
npm start
```

> L'app Angular parte su `http://localhost:4200`
